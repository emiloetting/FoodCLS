# FoodCLS
A university subproject on training a neural classifier for classification of food products based on [OpenFoodFacts](https://world.openfoodfacts.org/)

> [!NOTE]
> This repository is not primarily for active use.
> For access to the model, check out the [HuggingFace Repository](https://huggingface.co/emiloetting/FoodCLS) :)

> [!WARNING]
> The project is no longer maintained.  

The repository does not contain the trained model weights, which are to be found on the *HuggingFace*.
